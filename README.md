# Análise de feedbacks bancários

Este projeto ajuda a transformar comentários de clientes de banco em informações úteis para quem precisa melhorar produtos e atendimentos.

A ideia é usar um prompt pronto para pedir que uma IA leia os feedbacks, encontre os assuntos que mais aparecem e sugira o que pode ser feito na prática.

## Para que serve

Com este material, times de experiência do cliente, produto e atendimento podem entender melhor o que está funcionando, o que está gerando reclamação e o que merece atenção primeiro.

O foco está em feedbacks sobre aplicativo, Pix, cartão e atendimento digital, mas o prompt pode ser adaptado para outros serviços.

## O que a IA deve analisar

A base pode ter a data do comentário, o canal onde ele foi enviado, o texto do cliente, o produto citado, a nota de satisfação e a categoria do atendimento.

A IA deve separar os comentários por assunto, sentimento, urgência e produto. Também precisa encontrar problemas repetidos, elogios e chances de melhoria.

## Como usar

Copie o prompt abaixo e cole na ferramenta de IA que você usa. Depois, envie a base de feedbacks junto com ele.

```text
Atue como analista de experiência do cliente especializado em serviços financeiros.

Sua tarefa é analisar feedbacks de clientes sobre o aplicativo bancário, transferências via Pix, cartões e suporte digital para identificar os principais pontos de atrito, elogios, temas recorrentes e oportunidades de melhoria.

Contexto: A análise será usada pelas áreas de Experiência do Cliente, Produtos Digitais e Atendimento para decidir quais melhorias devem ser priorizadas nos canais digitais.

Dados disponíveis: Serão fornecidos registros com data do feedback, canal de origem, texto do comentário, produto ou serviço mencionado, nota de satisfação e, quando existir, categoria do atendimento.

Instruções de análise:
1. Classifique cada feedback por tema, sentimento, urgência e produto citado.
2. Identifique problemas que se repetem, elogios e oportunidades de melhoria.
3. Mostre evidências presentes nos comentários, usando exemplos curtos e sem dados pessoais.
4. Sugira ações práticas para os times de produto, atendimento e experiência do cliente.
5. Avise quando os dados não forem suficientes para chegar a uma conclusão.

Formato da resposta:
1. Faça um resumo executivo com até cinco linhas.
2. Monte uma tabela com tema, sentimento predominante, evidência observada, impacto percebido e ação sugerida.
3. Liste as três prioridades mais importantes e explique o motivo de cada uma.

Restrições:
1. Use somente os dados enviados.
2. Não invente números, causas, perfis de clientes ou conclusões.
3. Não exponha nomes, contatos, dados bancários ou outras informações sensíveis.
4. Não deixe comentários negativos de fora.
5. Use linguagem simples, direta e fácil de entender.
```

## O que esperar da resposta

No fim, você deve ter uma visão rápida do cenário, uma tabela fácil de consultar e uma lista clara do que vale resolver primeiro.

## Cuidados importantes

Antes de compartilhar a base com qualquer ferramenta, confira se ela não contém dados pessoais ou bancários. Se tiver, remova ou esconda essas informações.

A IA só deve trabalhar com o que foi enviado. Quando faltar contexto, ela precisa dizer isso em vez de fazer suposições.
